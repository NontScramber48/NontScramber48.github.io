Vivo Water — Production Reporting System

A daily production reporting web app for a drinking-water factory, replacing paper reports.

  • Daily report form: morning/afternoon shift times, machine breakdowns, output, NG (defect) counts
  • Auto-calculated KPIs: net run time, bottles per hour, NG % for film, cap and bottle
  • Dashboard with 1-day / 7-day / 1-month filters and NG trend charts
  • Excel export and A4 print layout; report history
  • PIN login backed by Supabase Auth with row-level security
